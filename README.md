# Smart ID Card PDF Cropper

A free browser-based tool to crop, straighten, resize, and arrange ID card front and back sides from PDF documents. Create high-resolution, print-ready PDFs with customizable card dimensions and printing layouts.

🌐 **Website:** https://subscriptlab.com

## ✨ Features

- **PDF Upload:** Upload PDF documents using drag-and-drop or file selection.
- **Four-Corner Selection:** Precisely select ID card corners for accurate cropping.
- **Perspective Correction:** Straighten tilted or angled ID cards.
- **Front & Back Cropping:** Extract and preview both sides separately.
- **Page Rotation:** Rotate PDF pages by 90 degrees.
- **Custom Card Dimensions:** Adjust card width and height in millimeters.
- **Multiple Print Layouts:** Choose side-by-side, stacked, or duplex printing.
- **Multiple Copies:** Generate up to 8 copies.
- **High-Resolution Export:** Choose 150, 200, 300, 400, or 600 DPI.
- **Paper Sizes:** Supports A4 and US Letter.
- **Print Preview:** Preview the final layout before downloading.

## 🔒 Privacy & Security

- PDF processing happens locally in your browser.
- Uploaded documents are not sent to the website by this tool.
- No account or registration is required to use the tool.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PDF.js – PDF rendering
- pdf-lib – PDF generation
- HTML Canvas API – Image processing and perspective correction

## 🚀 How to Use

1. Open the Smart ID Card PDF Cropper.
2. Upload your PDF document.
3. Click **Pin 4 corners** on the page containing the ID card.
4. Select the four corners in clockwise order.
5. Assign the selection as Front or Back.
6. Repeat the process for the other side.
7. Configure card dimensions, paper size, DPI, and print layout.
8. Preview your layout.
9. Click **Download print-ready PDF**.

## 📄 Printing Instructions

For accurate card dimensions:

- Select A4 or US Letter paper.
- Choose the correct card width and height.
- Print using Actual Size or 100% scaling.
- Disable Fit to Page.
- Verify dimensions with a test print.
